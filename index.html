2020 C++, Vulkan

Lift

Master’s thesis · github.com/GoncaloFDS/Lift

  • Lift is a real-time ray tracing renderer with an AI-accelerated denoiser, built with Vulkan and C++. Every frame is path traced and then denoised by NVIDIA’s OptiX, which is what keeps it real-time instead of progressive.
  • Path tracing and bidirectional path tracing both live in the same codebase, so I could compare which scenes each one struggles with.
  • This work was presented at WSCG 2021 as Lift: An Educational Interactive Stochastic Ray Tracing Framework with AI-Accelerated Denoiser, with Professor João Madeiras Pereira.
